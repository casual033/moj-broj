# Icon Options

Launcher foreground variants are stored in:

- `app-android/src/main/res/drawable/ic_launcher_foreground_minimal.xml`
- `app-android/src/main/res/drawable/ic_launcher_foreground_calculator.xml`
- `app-android/src/main/res/drawable/ic_launcher_foreground_kids.xml`
- `app-android/src/main/res/drawable/ic_launcher_foreground_tv.xml`

Current active icon is:

- `app-android/src/main/res/drawable/ic_launcher_foreground.xml`

To activate another option, copy selected file content into `ic_launcher_foreground.xml`, then rebuild/install.
